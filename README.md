\# Epiroc Pulse



Epiroc Pulse is a Windows desktop troubleshooting application for Epiroc field technicians.



The initial focus is diagnosing and troubleshooting network problems while connected to an Epiroc machine.



\## Primary Goals



\- Diagnose technician laptop and machine network connectivity.

\- Provide clear pass, warning, fail, info, and skipped feedback.

\- Guide technicians through troubleshooting steps.

\- Generate diagnostic reports.

\- Support future native Windows packet capture.

\- Maintain clean documentation and changelog discipline.
