\# Product Requirements - Epiroc Pulse



\## Purpose



Epiroc Pulse helps Epiroc field technicians diagnose and troubleshoot network problems while connected to Epiroc machines.



\## Primary Users



\- Epiroc field technicians

\- Automation/service personnel

\- Support teams reviewing diagnostic reports



\## Initial Capabilities



\- Detect active network adapters.

\- Show IP address, subnet, gateway, DNS, adapter status, and link information.

\- Validate whether the technician laptop is on the expected machine subnet.

\- Test gateway reachability.

\- Test machine device reachability.

\- Test TCP ports.

\- Detect common network issues such as APIPA address, wrong subnet, multiple active adapters, VPN interference, and unreachable gateway.

\- Display technician-friendly diagnostic badges.

\- Export diagnostic reports.



\## Future Capabilities



\- Native Windows packet capture using built-in tooling.

\- Network capture export.

\- Report generation based on existing Epiroc reports.

\- Guided troubleshooting flows.

\- Machine profile templates.

\- Advanced network analysis.
